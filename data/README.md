# Data

数据只按生命周期分区；公开源码快照仅用于可复现的离线资格审计。

- `raw/`：只读原始数据或外部数据指针。
- `processed/`：可再生成的预处理数据。
- `traces/`：匿名化、结构化的动作与验证工作负载 trace。

在加入数据前记录来源、许可、哈希、获取日期、隐私处理和拆分策略。

G2 冻结准备使用：

- `source-manifest.g2.yaml`：公开来源、固定版本、许可与压缩包哈希；
- `g2-event-selection.json`：确定性选择的 1,000 条事件 ID、拆分与资格审计；
- `raw/`：本地忽略的 τ-bench、AgentDojo、SafeToolBench 固定源码压缩包，不进入版本库；审计脚本直接读取压缩包，不保留展开目录。
