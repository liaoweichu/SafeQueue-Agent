# G2 Audit Packets

这里保存冻结前审计说明和可由项目 owner 签核的 review ledger。它们不包含 SafeToolBench 的原始风险指令；请依据固定压缩包、行定位器和哈希复核原文。

- `g2-hard-capability-pre-audit.md`：AgentDojo 与 Retail 的能力映射预审计；
- `g2-safetoolbench-review.md`：150 条危险校准记录的来源完整性审计与 owner review 规则；
- `g2-safetoolbench-label-review.csv`：逐条签核表，由 `scripts/generate_g2_safetoolbench_review_ledger.py` 可重建。
